# ロードバランス・クロニクル（仮）

普通にRPGとして遊んでいたら、IT資格の知識が身についている ―― ブラウザで動く3D RPG（PWA）のプロトタイプです。
最初のテーマは **負荷分散（Load Balancing）**。

- 設計書：[docs/design.md](docs/design.md)
- 技術：TypeScript / Vite / Babylon.js / IndexedDB / PWA（サーバー不要）

## 起動（ダブルクリック）

- `ゲームを起動.bat` … 開発サーバーを起動してブラウザで開く（初回は自動で `npm install`）
- `PWA確認用に起動.bat` … 本番ビルドを作って、インストール・オフライン動作を確認できるサーバーで開く

どちらも終了するときは黒い画面を閉じます。

## 遊び方

移動はありません。拠点メニューからクエストを選んで出撃し、ウェーブごとの連戦（3ウェーブ目がボス）を戦います。

| 場面 | 問題の結果で決まること |
|---|---|
| ⚔ 攻撃 | 与えるダメージ（速攻正解×1.8／正解×1.3／不正解×0.6／早押しミス×0.3） |
| 🛡 防御（敵の攻撃の前） | 受けるダメージ（速攻正解×0.15／正解×0.5／不正解×1.2／早押しミス×1.5） |
| ★ 経験値（勝利後） | 獲得EXP（速攻正解×1.6／正解×1.25／早押しミス×0.6／不正解×0.4） |

- 選択肢は **1〜4キー** かクリック。タイマーの金色の部分が「速攻」です（問題文が長いほど長め。「集中の護符」で延長）
- 選択肢の並びは毎回シャッフル。**間違えた問題は1問あけて3回出し直し**、2回続けて正解した問題は卒業して新しい問題が出ます
- 不正解のときは正解と解説が出ます（クリック / Enter で次へ）
- 敵の名前をクリックすると攻撃する相手を変えられます
- 倍率は `src/data/progression.json` の `quiz.outcomes` で変更できます

### 出題範囲（基本情報技術者試験の全分野・215問）

| クエスト | 分野 |
|---|---|
| 交易路の防衛 | 基礎理論、アルゴリズムとプログラミング |
| 古代書庫の迷宮 | コンピュータ構成要素、ハードウェア、ソフトウェア |
| 天空の塔 | システム構成要素、データベース |
| 風の港町 | ネットワーク、ヒューマンインタフェース、マルチメディア |
| 城壁の攻防 | セキュリティ |
| 職人街の工房 | システム開発技術、ソフトウェア開発管理技術 |
| 王城の評議 | プロジェクトマネジメント、サービスマネジメント、システム監査 |

どのクエストにも最初から挑戦できます。自分のレベルが低いときは、敵が「自分のレベル＋1」相当まで弱くなります。

### 問題の追加

問題は `src/data/questions/<分野>.json` にあります。ファイルに足すだけで出題されます（起動時に形式とIDの重複をチェック）。収録している問題は、試験の出題範囲に沿って作ったオリジナル問題です。お手元のIPA過去問を使う場合は、`source` に `{ "type": "ipa", "label": "令和○年度 基本情報技術者試験 科目A 問○" }` のように出典を書いて追加してください。

```json
{ "id": "nw-99", "knowledgeIds": ["network"], "examIds": ["fe"],
  "source": { "type": "original", "label": "オリジナル問題" },
  "stem": "問題文", "choices": ["正解", "誤答1", "誤答2", "誤答3"], "answer": 0, "explanation": "解説" }
```

## キャラクター登録（Tripo等のGLB）

メニュー → キャラクター → 「キャラクター登録を開く」。
GLBを選ぶ（またはドロップ）→ 3Dプレビュー → アニメーション（待機/歩行/走行）をプルダウンで割当 → 大きさ・向き・高さを調整 → 「歩かせてみる」 → 登録。
手元にGLBがない場合は「サンプル：主人公 / パートナー」で試せます（`public/samples/`、`npm run gen:sample` で再生成）。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # ロジックの単体テスト（戦闘・習熟度・ドロップ・ギミック・バランス）
npm run build      # 本番ビルド（dist/）
```

ゲームデータはすべて `src/data/*.json`。新しい知識・敵・クエスト・装備はJSONを足すだけで追加でき、起動時にスキーマと参照の整合性が検証されます。

## デプロイ（Cloudflare Pages）

GitHubリポジトリをCloudflare Pagesに接続し、次の設定にします。

| 項目 | 値 |
|---|---|
| Framework preset | None（または Vite） |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node.js | `.node-version`（22）で指定済み |

`main` へのpushで自動デプロイされます。PWAの更新判定に使うファイルは `public/_headers` でエッジキャッシュしないようにしています（男盛と同じ方針）。
